AK GARMENTS WEBSITE
===================

Static multi-page website package.

To preview locally:
1. Extract this folder.
2. Open index.html in a modern browser.

To publish:
- Upload the contents of this folder to the public root of a static host, or
- Push the folder contents to a GitHub repository and enable GitHub Pages.

Pages:
- index.html (Home)
- booking.html (WhatsApp wholesale enquiry)
- faq.html
- privacy.html
- license.html

Booking form:
- Required fields are validated in the browser.
- Submit opens WhatsApp at +91 90822 77289 with a URL-encoded message.
- No enquiry is stored by this static site; the visitor must review and send the WhatsApp message.

Brand facts are limited to the information supplied by AK Garments. Unknown MOQ, pricing, lead times, delivery, customisation and payment terms are referred to Ilyas for confirmation.
